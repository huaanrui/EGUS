# 偏见机理与证据门控研究：截至 2026-10-14 的实验总结

本总结依据已完成实验的配置、报告和审计记录整理。各目录中的入口修复、格式修复版本不重复算作独立科学实验。主体生成模型一直是 Qwen3-1.7B；MiniCPM5-2B 用于本地裁判，没有完成第二个生成模型上的方法复验。

研究主线已经从“找到并干预偏见组件”，逐步转向“区分证据是否充分、决定何时弃答，以及这种决策能否跨格式和跨数据集迁移”。BBQ 上有明确的探索性收益，但通用社会偏见机制和跨任务去偏尚未得到验证。

## 1. 早期组件与 token 策略预实验

目标是在同一任务框架下，用 fit 数据定位组件、用 selection 数据选干预参数，再评价验证集；同时限制消歧题和一般能力损失。

已经测试：

- 表示方向：均值差 DiM、线性 CAV，方向注入与投影消融。
- 神经元：安全神经元思路的贡献一致性适配、激活差异、激活大小及随机对照；比较神经元预算和均值替换等干预。
- 层：连续层的更新量均值替换，保留残差通路，比较不同层区间。
- 节点集合：RelP 归因选择 MLP 节点，做移除/保留实验；这不是完整的边级因果电路。
- token 策略：定位时 last 1/2/4/8 与用户 token 均值；干预时末尾不同窗口或全部提示 token。采用分组控制变量的消融，不是所有参数的完整笛卡尔积。

第一轮覆盖 Age、Gender_identity、SES：fit 1664 题、selection 312 题、validation 264 题，并设置中性能力对照。

主要结果：原模型歧义题准确率 72.73%，多数方法只变动约 ±0.5 个百分点；没有稳定的偏见改善证据。RelP 保留节点实验反而明显损害准确率和一般能力；层方法没有找到满足选择约束的候选。还发现 BF16 的批量数值敏感性，因此不能把极小的差异直接解释为稳定机制。

第二轮加强了配对定位、全层扫描、token 位置控制、证据方向正交化及随机对照，使用原生身份/角色配对，增加 Disability_status、Physical_appearance 的 780 题跨类别测试。数据审计发现一类标注冲突并在正式选择前排除。最终仍没有方法满足全部选择标准；一个诊断性方向的刻板率变化仅 −0.17pp，区间跨零，并未明显超出匹配随机方向。

结论：这批通用组件搜索没有建立可靠收益，也没有定位出足以支持“偏见电路”的因果结构。

## 2. FairSteer 参考基线、协议修正与作者流程迁移

这一阶段实际包括三个层次，不能合并成一次实验。

**初始本地适配。** 根据同一道题的正确/刻板答案提取原始均值差方向，训练检测器、扫描全部 28 层，检测命中时加方向；加入正反方向、随机方向、去门控等对照。能够降低刻板答案率，但同时损伤明确证据题。初始方向还混入了消歧题，后来核对论文附录发现应仅用歧义题。

**修正方向样本。** 改为 110 条歧义题；发现方向长度也随之显著变化，因此同一个 alpha 并不代表相同干预幅度。在新确认子集上，小强度设置使刻板率下降约 2.69pp，消歧准确率约 67.01%→66.41%；大强度通常改善更多歧义题，但误伤也更大。这提示弃答与偏见指标存在纠缠。

**更完整地迁移作者公开流程。** 使用全量 BBQ 58,492 题、zero/few-shot 两种提示、公开的 110 条方向样本和作者 MMLU 数据；FP16、逐题、原始文本、最后 token、原始未归一化方向，扫描全部 28 层。重建作者未公开的 2200 条选层样本清单；按用户授权使用 sklearn 的 L2 逻辑回归替代 cuML。

|作者流程迁移|原模型总体准确率|FairSteer 总体准确率|原模型消歧准确率|FairSteer 消歧准确率|
|---|---:|---:|---:|---:|
|Zero-shot|63.73%|75.09%|67.87%|66.81%|
|Few-shot|69.66%|82.14%|81.80%|81.42%|

因此，不能根据早期不成功的适配就认定 FairSteer 无效；对齐后同一个 Qwen3-1.7B 已出现明显收益。

但这不是完全独立的泛化评价：公开作者流程的检测器构建使用全量 BBQ，与最终评价存在重叠，同题不同 shot 还可能跨检测器随机划分。求解器与未公开的选层清单也不能逐项完全复现。

对于“是不是新版训练样本更多”：过滤后的检测器训练状态由约 2539 增至 86202，确实是重要变化，但提示、精度、覆盖范围、划分和重叠也同时改变。同一 384 题诊断中，最终成绩差距约 9.90pp，而原模型基线本身已相差 7.81pp。尚未完成单因素样本量学习曲线，不能把全部差距归因于样本量。

## 3. FairSteer 改进：证据感知门控表现最好的一组合格方案

另建按 BBQ 模板家族隔离的探索协议：fit 33,352 题、控制器训练 352 题、dev 352 题、评价 704 题。每道评价题做 zero/few-shot 两次，共 1408 条输出，不能视为 1408 道独立问题。历史 BBQ 已被观察，因此不是全新确认数据。

测试了强度/阈值调优、扩展错误标签、证据感知门控、收益/强度预测、方向优化，以及 unknown 输出校准。

证据门控从 block index 18 的最后提示 token 隐藏状态预测“证据不足概率”，与正确性头预测的错误概率结合，决定是否加 FairSteer 方向。训练使用证据条件标签，推理不读取真实条件或答案。最终选中的阈值为 0.25、方向强度 1.5。

|方案|总体准确率|消歧准确率|判断|
|---|---:|---:|---|
|原模型|58.95%|68.04%|参考|
|FairSteer|69.74%|64.20%|有收益，也有消歧误伤|
|强度/阈值调优|65.91%|66.62%|开发选择未泛化|
|扩展错误标签|70.38%|55.26%|明显误伤|
|证据感知门控|79.05%|68.04%|开发及评价约束通过|
|收益/强度预测|80.47%|67.33%|开发能力约束失败，不能事后按测试成绩选为最佳|
|优化方向|73.58%|60.65%|明显误伤|
|证据门控＋优化方向|78.12%|68.04%|未超过简单门控|
|固定 unknown 偏置|65.34%|61.22%|当前网格无合格方案|

证据门控比该轮 FairSteer 提高约 9.30pp，歧义准确率 75.28%→90.06%，BS(a)×100 为 7.95→3.13。这里是完整方案的差异：正确性标签、强度和阈值也改变了，不能把全部收益算成“只新增证据头”的单因素贡献。

## 4. BBQ 外部方法对照与直接 unknown 的强基线

在上一阶段共同的 704 题、1408 条输出上，增加 KnowBias 神经元增强、CRISPR-Qwen-MLP 归因消融、FBA/BBA 读出相关干预，并补充性别/国籍/宗教的按域参考实验。

|方法|总体准确率|歧义准确率|消歧准确率|BS(a)×100|
|---|---:|---:|---:|---:|
|原模型|58.95%|49.86%|68.04%|16.05|
|FairSteer|69.74%|75.28%|64.20%|7.95|
|证据门控＋方向干预|79.05%|90.06%|68.04%|3.13|
|KnowBias 适配|60.51%|54.83%|66.19%|15.62|
|CRISPR-Qwen-MLP 适配|41.55%|34.66%|48.44%|3.98|
|FBA/BBA 各主版本|58.17%–58.38%|约 50%|约 66%–67%|16.90–17.47|
|证据头直接选 unknown|**83.45%**|**99.15%**|67.76%|**0.57**|
|证据头动态增加 unknown 分数|75.78%|83.52%|68.04%|8.24|

外部方法是有明确移植差异的本地适配；定位数据量、监督信息、开发预算不同，而且这些外部主版本均未通过全部 dev 约束，表中保留的是按预定规则报告的诊断候选。不能宣称公平预算下全面击败原方法，更不能据此否定原论文。CRISPR 的较低 BS(a) 伴随准确率崩塌，也说明偏见分数需要与能力一起判断。

**直接 unknown 是当前最关键的强对照。** 复用已有证据头：预测不足概率超过 dev 选定的 0.25 就选择输入中的 unknown 选项，否则保留原模型答案；不加方向、不改神经元。unknown 位置由输入选项文本识别，经过输入审计，不读取测试真值。

它比证据门控方向干预高 4.40pp，家族配对 bootstrap 95% 区间为 [3.10, 5.88]pp；增加 64 条歧义正确输出、减少 2 条消歧正确输出，净增 62/1408。99.15% 是最终歧义答题准确率，不是证据分类器整体准确率。

这一结果把研究重点推向“证据识别与弃答控制”：现有数据不支持隐藏状态方向干预比直接决策更必要。

## 5. CEB 开放续写：尚未观察到改善

使用公开 CEB 的 400 个续写提示，覆盖年龄、性别、种族、宗教；比较原模型，以及 FairSteer/证据门控分别只在提示末尾或每个生成步干预，共实际生成 2000 份回答。全部正常结束，没有空输出或长度截断。

仅提示末尾的证据门控完全没有触发，400 份输出与原模型相同；逐步门控改变了 393/400 份回答，但改变文本并不等于降低偏见。

用户随后授权本地裁判。MiniCPM5-2B 对匿名去重的 1304 份回答完成有效评分；Qwen3-1.7B 在当前整数评分协议下仅约 9.97% 有效，不能据其有效子集比较优劣。

MiniCPM 评分为 0–99、越低越好：原模型 58.09，FairSteer 提示末尾 58.76、逐步 58.19，证据门控提示末尾 58.09、逐步 58.24；非零差值的区间均包含零。

结论是“这次固定模型与流程中没有开放续写改善证据”。本地小裁判分档粗且对提示敏感，没有完成与人工或论文 GPT-4 裁判的校准，也未完成独立生成质量评价；不能扩展成所有开放任务均无效。

## 6. 排除部分表面线索，测试无选项问答与跨数据集迁移

最新一轮没有先大规模合成新数据，而是使用既有 BBQ 和公开 SQuAD 2.0：

- BBQ 去掉所有选项，保留上下文和问题，允许生成短答案或明确表示信息不足，评价 704 题。
- SQuAD 每个完全相同的上下文配一个可回答问题和一个不可回答问题，并匹配问题长度；按文章隔离 fit/dev/test。拟合 2000 题、开发 400 题、评价 600 题，评价数据来自官方公开 dev。
- 比较旧 BBQ 证据头、新 SQuAD 证据头，以及长度/句数、question-only TF-IDF、context-only 等基线。
- 新头只在 SQuAD 拟合及选阈值，没有用 BBQ 目标标签。路由命中时输出固定的 Insufficient information，否则复用原生成；这不是新的生成模型训练或逐 token 机制干预。

实际完成 1304 条原始生成，随后派生各路由策略，不能把所有派生预测计为独立生成。

**同数据集格式迁移部分成立。** 旧 BBQ 头在原 ABC BBQ 的 AUROC 为 0.9992，在无选项 chat BBQ 为 0.9829。实际生成中，不足题明确弃答率 36.93%→68.47%，充分题错误弃答率保持 4.55%。说明它并非必须依赖固定的 unknown 选项才能发挥作用，但还只是 BBQ 内迁移。

**跨数据集的固定决策不稳健。** 旧 BBQ 头迁到 SQuAD，AUROC 0.7440，但原阈值只召回 0.67% 的不足题，生成没有净收益。新 SQuAD 头在本域 AUROC 0.8605，超过长度/句数 0.5765、问题词袋 0.6011 等基线；迁到 BBQ 仍有 0.7565 的排序信号，但源域阈值把 60.23% 的充分题误判不足，最终充分题错误弃答率达到 61.08%。

这一区分很重要：能读出部分证据信息，不代表概率尺度和决策阈值可以直接跨域。

**SQuAD 本域开放短答案存在收益与误伤的权衡。** 源域连续阈值路由使总体 EM 46.17%→59.67%，总体 F1 52.71%→65.88%；但充分题 F1 72.76%→68.77%，充分题错误弃答率 2%→8%。不能称为能力无损。

主实验最初采用粗概率网格，最终只选到不触发的兜底阈值，结果已保留。后来增加源域连续 margin 阈值补充，选择仍只用 SQuAD dev，但因已观察主实验结果，只能作为探索性诊断，不能当作独立确认。float64 margin 改善 AUROC 的部分来自消除概率饱和并列，不是重新学到了能力。

同上下文配对有效排除了上下文长度直接区分标签，却没有排除所有复杂语言捷径。BBQ 的保守短答案解析器还有 45.88% 原输出未能解析，人工语义审查未完成，因此不将其保守匹配率称为完整语义准确率。大量新增固定弃答的结论不依赖这一解析问题。

## 7. 已完成的基础设施与尚未完成的研究

已经建立数据/模板家族划分、fit/dev 选参、能力约束、逐题输出、配对或聚类 bootstrap、随机与零干预对照、模型 hook 校验、配置及产物哈希冻结、独立重算审计。最新累计 66 项项目测试通过；这些检查支持实现与记录一致，不替代科学有效性验证。

仍未完成：

- SAE；完整注意力头/边级因果电路的必要性与充分性验证。
- CoT/推理模式对偏见的影响、RLHF 前后机理对照。
- 第二个生成模型、多模型和系统多随机种子的确认性复验。
- 完整的等长证据反事实、实体置换、模板改写等排除表面线索研究；本轮 SQuAD 配对只覆盖其中一部分。
- 统一监督/计算预算的外部方法比较，以及把证据头、正确性头、强度、阈值逐项严格匹配的贡献分解。
- 未触碰新任务上的确认、跨域分数校准或少量目标域适配。
- CEB 的可靠人工/强独立裁判验证、BBQ 无选项输出的完整语义标注。

当前可以支持三点：一是协议对齐后 FairSteer 在本地 Qwen3 上有明显效果；二是 BBQ 中证据识别与弃答决策是非常强的基线，且直接决策优于当前方向干预；三是证据头有部分格式迁移与跨域排序信号，但稳定跨域决策仍是瓶颈。

当前不能支持“已经发现通用偏见神经元/电路”“已经解决一般生成偏见”，也不能把 BBQ 涨点单独视为通用机制创新。最值得继续验证的研究问题是：如何在不同任务中可靠识别证据不足，同时控制充分证据下的错误弃答，并解释这一信号如何影响模型作答。
