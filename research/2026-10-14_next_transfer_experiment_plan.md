# 下一轮：封闭选择迁移与证据门控的作用边界

日期：2026-10-14。状态：实验设计草案；尚未下载新目标数据、冻结清单或启动推理。本文不修改已有实验代码、配置、拟合产物或结果。完成原始数据审计后，另存可执行配置、样本清单和冻结协议；不得根据目标测试表现修改本计划的主比较。

## 1. 本轮问题与优先级

优先做 BBQ → SynthBias，再做 BBQ → WinoBias/Winogender。前者检验新的数据分布中是否仍能区分证据不足与充分；后者检验需要选出具体答案时是否有帮助。Bias-in-Bios 放在第二阶段，开放短问答在相同样本上继续做。暂不铺开新的神经元、电路和 SAE 搜索。

需要区分三个问题：

1. **识别迁移**：只在 BBQ 拟合的证据头，能否在另一个数据集识别信息不足？
2. **决策迁移**：源域选定的阈值，在目标域是否保持召回与低误伤？
3. **干预迁移**：同一个方向及门控，是否改善目标模型的答案？隐藏状态干预是否优于直接选择 unknown？

现有结果提示三者不能互相替代。旧 BBQ 头在 SQuAD 无选项问答上的 AUROC 为 .7440，但原阈值下不足召回仅 .67%；反向 SQuAD 头迁到 BBQ 时充分题假阳性达 60.23%。同域 BBQ 的直接 unknown 策略又优于隐藏状态门控。因此本轮不预设向量干预必然优胜。

已有开放问答记录：[findings](2026-10-14_evidence_openqa_findings.md)。已有统一比较：[BBQ comparators](2026-10-13_bbq_comparator_findings.md)。

## 2. 文献依据及不能混用的结论

- [CRISPR，第 4.6 节及附录 C](https://arxiv.org/html/2311.09627)：报告源任务定位神经元后用于其他任务；源数据选择剪枝量的 CRISPR，与按目标评价准确率选择剪枝量的 CRISPR† 是两种设置。我们借鉴前者，并单独设置只用目标校准集的适配组，不用目标测试集挑参数。
- [SynthBias 论文，第 4、5 节](https://arxiv.org/html/2505.23996)及[官方数据](https://github.com/apple-aiml-research/ml-synthbias)：公开的人类核验性别—职业指代数据，有信息不足和可明确指代两类。官方仓库更新称去重后为 31,728 条，实际以锁定版本为准。论文也有三选一，但第三项为 “None of the above”，且不足题主要用不确定性评估；我们显式采用 “Cannot be determined from the context” 并将不足题标为该选项，属于派生的 BBQ 风格协议，不能冒充原论文指标复现。
- [WinoBias 官方仓库](https://github.com/uclanlp/corefBias)、[原论文](https://aclanthology.org/N18-2003/)及[Winogender 官方仓库](https://github.com/rudinger/winogender-schemas)：已有指代答案和性别变体，适合比较准确率及配对敏感性。WinoBias Type 1 的定义不等于 SynthBias Type 1，不能直接将其全标为 unknown。
- [Bias-in-Bios 数据版本说明](https://huggingface.co/datasets/LabHC/bias_in_bios)：有职业标签、性别属性与既定划分，可验证实际分类任务的群体性能差距。这里的自然语料差距不是自动成立的身份因果效应。

|阶段|源 → 目标|主要目的|优先评价规模|可支持的结论|
|---|---|---|---|---|
|A1 主实验|BBQ → SynthBias，三选一|换数据，尽量保持答案格式|目标 test 约 2,000 条，另设 calibration 约 400 条|证据识别、固定阈值、干预的跨数据迁移|
|A2 必做对照|BBQ → WinoBias，二选一|无 unknown 时的真实答案改善|官方 test 全量，分 Type 1/2 报告|指代任务的收益或误伤|
|A3 配对验证|BBQ → Winogender，二选一|性别变体下稳定性|官方 720 条，按模板聚类|配对身份敏感性与正确率|
|B1 格式分解|同一 BBQ 源 → 同一 SynthBias test，移除选项短问答|在目标样本不变时改变输出形式|与 A1 完全相同，不另挑容易样本|格式迁移是否额外损失|
|B2 应用任务|BBQ → Bias-in-Bios，28 类职业|更远的真实文本分类迁移|test 约 2,800 条，分职业×性别抽样|分类效用与群体差距|

阶段 A 全部完成和报告，不能看到 A1 成功便省略 A2/A3，或依据结果更换主数据集。阶段 B 单独冻结协议；优先 B1，再 B2。现阶段不需要我们自行生成新场景，也不需要付费裁判。

### A1：SynthBias 适配

输入保留原句，并问目标代词指谁；候选为两种职业和明确的无法确定选项。不得将 type、is_stereotypical、正确职业字段名等元数据放进提示。

关键风险：官方说明的 `occ_1` 在 Type 2 中就是正确指代职业。因此不能直接把 `occ_1` 永远排在 A。候选顺序须用独立固定种子随机化，并平衡正确答案位置；同一个性别配对保持相同职业—选项映射。unknown 的位置也随机，不能固定 C。

不足题金标来自原数据的歧义标注；充分题金标来自原数据 referent。改写的是提问和选项包装，不改上下文、职业和原始语义标签。该派生版本命名 `synthbias_bbq_style_v1`，不使用“官方 SynthBias accuracy”名称。

先按无序职业对划分目标 calibration/test/reserve 池，建议约 20%/30%/50%；同一句的代词替换、近重复语句和关联模板必须在同池。跨职业对重复模板如存在，合并连通分量后再划分。按固定种子 20261014 从池内采样 calibration 约 400、test 约 2,000，保留完整身份配对，尽量平衡不足/充分及充分题 pro/anti。精确条数和家族数由审计决定，不能为了凑整拆配对。另从 reserve 取不超过 64 条仅做转换审查，未用部分保留后续新协议确认。

按职业对隔离会使校准更难，但能减少同职业搭配模板泄漏。报告实际覆盖职业、职业对、完整配对、各条件条数以及排除原因。不会将 2,000 条或多个选项排列当成 2,000 个独立家族。

同一 test 预先固定一个主选项排列，另做 A/B/C 循环移动的两个排列作为位置鲁棒性诊断；三个排列绑定统计。主结果不能从三个排列中择优。

### A2/A3：无弃答任务

WinoBias、Winogender 保留原指代金标，转换为两个候选实体。模型必须在候选中选择；不额外添加 unknown。WinoBias Type 2 作为较明确证据的主要切片，Type 1 保留但单独报告其语义歧义限制；不能根据模型答错与否删除题目。

保留 pro/anti 和性别变体。按基础句子/模板配对；主候选顺序随机并在配对内绑定，反转顺序作为独立诊断。Winogender 的职业身份可能本来就与代词的语义匹配有关，只在原数据设计的可比变体内测一致性，不能强求所有身份变化不影响答案。

直接 unknown 策略在此为“不适用”；为了复用推理可以原样输出基线，但必须标为 no-op。它不变差不能当作跨任务方法成功。另记录证据头触发率：这些带既定答案的任务中，高触发率可以暴露头的误用，但 WinoBias Type 1 不宜全部作为无噪声的充分标签计算二分类 FPR。

## 4. 冻结迁移、校准、重新拟合分别报告

|设置|可访问目标数据|可改变参数|表述|
|---|---|---|---|
|Z：主实验|测试输入仅用于预测；金标仅用于最后评价|无|源域拟合、源域选择后的冻结迁移|
|K：校准诊断|独立目标 calibration 的输入及标签|门控阈值一个标量；方向、头、层、强度全部不变|有监督目标域校准|
|R：后续参考|独立目标 train/dev|重新拟合头等，另报预算|目标域训练参考，不是迁移|

Z 先冻结预测和结果文件，再执行 K。K 仅用于 SynthBias；拟定 100/400 条两个嵌套预算，按配对抽样。只调整各门控自己的阈值，在 calibration 上要求充分题被判不足的比例不超过 2%，并在最终准确率不比基线低超过 1pp 的候选中最大化平衡准确率；包括不触发候选。若没有可行非零干预，保留 no-op。报告实际计数与区间：400 条中的充分样本很少，2% 是选择约束，不是目标风险保证。连续阈值使用 float64 margin 或稳定组合分数，候选来自校准分数的相邻边界，保存完整选择轨迹。

直接 unknown 的阈值与乘积门控的阈值不是同一参数，不能用相同数值声称相同触发策略。K 的各方法分别校准，但目标样本预算相同。

不会根据 test 选阈值、方向符号、层、强度、prompt 或 neuron 数量。test 上的全阈值曲线只作为描述性图，不从中选“最佳方法”。AUROC 是事后评价统计，不等于选用了目标阈值。

BBQ 旧测试与全量作者协议结果已被看过，所有 BBQ 重划分属于探索性。复用 `fairsteer_improve_20261013_v2` 的家族隔离头/方向，不能复用在全量 BBQ 上拟合的作者协议头来宣称干净的 BBQ 测试或类别留出。新外部测试是新目标数据评价，也不能承诺模型预训练从未见过这些公开数据。

## 5. 方法：少量关键比较

第一阶段固定 Qwen3-1.7B、FP16、block index 18、最后一个 prompt token、zero-shot、原始 ABC 风格，不开启 thinking。这是旧方法迁移，不在目标上重新寻找 token 聚合方式。二选一保留同样提示外壳，仅删除不适用选项。

主方法使用现有冻结文件中记录的参数，先核验哈希和实际代码，不只依据文字手工重建：

1. **Base**：无干预。
2. **FairSteer**：家族隔离版本的头、方向及源域阈值/强度；注明 sklearn 求解器差异。
3. **Evidence-steer**：现有证据乘积门控及源域选定参数。
4. **Evidence-direct**：同一证据头直接路由到 unknown，仅在显式提供该选项的任务适用。
5. **Matched correctness gate**：与 Evidence-steer 相同 expanded 正确性头及方向，只移除证据因子。其阈值/强度只依据已有源域 dev 选择，使用同样候选预算。用于分离正确性标签扩展与证据因子的贡献。

诊断对照：固定 unknown logit 偏置（仅源 dev 选系数）、总选 unknown 的退化基线、与 Evidence-steer 相同触发率的随机路由（10 个固定种子，仅解释选择质量）。随机路由可匹配该批目标输入的平均触发率，但不读标签，不能称可部署的逐题策略。

关键的“同门控不同动作”对照：复用 Evidence-steer 的逐题触发掩码，触发时直接选 unknown，其他题输出基线。这个对照与第 4 项独立：第 4 项用历史独立证据阈值；同掩码对照才控制了是否触发这个变量。它能判断收益来自找对题，还是隐藏方向本身。

令证据头分数为 e(x)，正确性头为 c(x)，则旧 Evidence-steer 的形式是：

\[
g(x)=\mathbf{1}[(1-c(x))e(x)>\tau],\qquad
h'_{18,t_*}=h_{18,t_*}+\alpha g(x)v.
\]

其中 t* 是 prompt 最后一个有效 token，c、e 从未干预前的隐藏状态计算；不在 hook 中递归重算，不用金标控制 g。若动作是 direct，则 g=1 时选择当前题的 unknown 位置，而不是恒定输出某个字母。

KnowBias、CRISPR-Qwen-MLP、BBA/FBA 可在后续补充已有冻结版本迁移，但必须保留“适配实现”和之前源 dev 约束失败的标记。不能因其源表现较弱而对我们的方法另给更多目标调参预算；也不能把它们当作已严格复现的原论文最佳结果。首轮不重新搜索这些方法。

## 6. 指标与预先判据

### SynthBias 三选一

主指标为两种证据条件的平衡准确率：

\[
\mathrm{BA}=\tfrac12\{\Pr(\hat y=u\mid\mathrm{ambig})+
\Pr(\hat y=y\mid\mathrm{clear})\}.
\]

同时完整报告：总体准确率、不足题 unknown 召回、充分题准确率、充分题错误 unknown 比例、门控触发率/充分题触发率。充分题里分别给 pro/anti 准确率、带符号差及绝对差；性别配对两题同时正确比例、预测翻转率。差距缩小但两组都更差不能称有效去偏。

表示诊断报告 float64 证据 margin 的 AUROC/AUPRC、固定阈值的 TPR/FPR，并比较长度/标点等表面特征与 question-only 基线。AUPRC 随类比例变化，报告正例比例。目标训练的表面基线若后续加入，必须另用目标训练池，不与冻结源头混为零样本公平比较。

另报告答案概率上的身份配对差异、充分题 gold log-probability 的变化，作为准确率以外的诊断。若计算 UCerF，只在独立的论文对齐设置下按原式报告，不能拿我们的明确 unknown 三选一结果直接对照论文原数值。

预期实用收益的门槛（设计选择，不是预告结果）：相对 Base，BA 至少 +2pp，同时充分题准确率损失不超过 1pp；相对 FairSteer 也报告同样差分。若要主张隐藏状态干预有额外价值，还需优于 Evidence-direct 与同门控 direct，对所有目标保留结果。95% 家族聚类区间若不能支持这些结论，标为不确定；“点估计损失 ≤1pp”不等于统计上已经证明非劣。

### WinoBias / Winogender

总体及分条件准确率、性别/刻板方向差距、配对两题都正确率、gold log-probability、选项反转敏感性。只有公平差距改善且准确率维持，才支持更广的去偏。高准确率天花板、原始偏差很小或区间较宽时如实报告，不能只保留有显著提升的切片。

### 统计单位

按配对/模板家族进行方法间配对 bootstrap，固定 2,000 次；SynthBias 额外按职业对聚类做稳健性检查。多个排列、性别变体和同题多种格式不是独立样本。主比较预先指定 Evidence-steer vs FairSteer、Evidence-steer vs 同门控 direct；跨目标正式显著性主张使用 Holm 校正，其他多方法分析标记探索性。不把诊断 AUROC 与干预增益混成一个分数。

## 7. 原先格式迁移问题如何拆开

第一阶段完成后，在同一批 SynthBias test 上移除选项，要求输出职业短名称或固定无法确定短语。使用完全相同的源头/方向/阈值，先只在 prefill 最后 token 干预一次；不把逐生成 token 重复干预混进主比较。

对照矩阵：

|目标样本|有选项|无选项|
|---|---|---|
|旧 BBQ 留出题|历史源格式参考|已有结果，只做必要的同协议对齐|
|新 SynthBias|本轮 A1|后续 B1，同一题及同一个源拟合产物|

这比“BBQ 选择题直接跳到 SQuAD 开放问答”更容易分解数据与格式因素。仍只能支持短答案迁移，不能据此称长篇自由生成有效。

评分先精确职业名称/明确弃答，再对未解析输出做盲化人工语义审查；未解析比例和区间单列，不能把未解析一律当成语义错误后夸大方法收益。复用已完成 CEB 生成作为历史负结果；若后续重评，先提升评分可靠性并增加效用指标，不能靠换一个有利的小裁判宣布成功。FairMT 多轮留到更后阶段。

## 8. 只有定位出边界后才做的改进

- AUROC 较高但固定阈值失败，K 校准改善：优先研究分数尺度和跨域校准，结论是有限监督适配，不是无条件迁移。
- AUROC 接近随机且 K 无帮助：源头未学到可泛化特征；下一轮考虑多来源 QA 训练、留一数据集验证，并控制每个来源的数据预算。不能继续只加密阈值网格。
- Evidence-direct 与同掩码 direct 已能解释全部收益：将工作定位为证据识别/选择性回答，诚实报告表示干预没有额外优势。
- Evidence-steer 在充分反刻板题、无 unknown 任务上也改善：再对同一批配对样本做组件因果定位，例如干预/恢复关键表征及随机方向等范数对照；仅分类头可读出不能称机制已经证实。
- 只在某个固定选项排列成功：优先检查读出和标签位置偏差，不能先归因于通用社会偏见表征。

可选 BBQ 留类别实验必须对每一留出组重新拟合方向和所有头，排除包含该属性的交叉类别/等价家族；旧全类别头不构成未见类别迁移。现有层 18 也是历史选择，因此将此实验标为探索性的受控类别留出。

## 9. 执行顺序与工程交付

1. 数据获取与审计：固定上游 commit/revision、文件 SHA256、许可证；验证类型、答案和配对；记录下载数/去重数/保留数。只看 reserve 审查样本，先不跑目标 test 的调参探索。
2. 数据适配器：统一存 `dataset/source_id/family_id/pair_id/split/context/question/choices/gold/condition/group_metadata`。元数据与模型输入隔离。保存实际 prompt、选项映射和构造种子。
3. 冻结源资产：核验 improvement v2 的 head/direction/hash/alpha/tau；同源 baseline 抽查；若为诊断新选源参数，先在源 dev 完成再读目标输出。
4. 小规模实现验证：reserve 上核验答案映射和候选 token；验证 no-op=Base、alpha=0、unknown 位置、padding/position_ids、batch1 与 batch4。裁剪过长输入必须先记录，不能静默截掉正确证据。报告候选外概率质量；受限候选 argmax 与实际自由输出分开称呼。
5. 运行 A1/A2/A3 的冻结主预测。可复用原模型特征和同一方向/强度的真实干预 logits；路由只读预干预特征，不为每个阈值重复 GPU 前向。不要假装 CPU 改 logits 等于隐藏状态干预。
6. 锁定主预测后，运行 K 的阈值校准与固定目标评价，另表报告。保存源/目标选择轨迹，不覆盖 Z。
