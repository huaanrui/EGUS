# 首轮实验协议：社会线索、用户意见与证据的因果交互

状态：研究建议，尚未执行。日期：2026-10-07。

对应综述：[大模型偏见机理调研](2026-10-07_llm_bias_mechanisms_review.md)。主模型建议使用本地 `F:\LLMs\Qwen3-1.7B`，实验代码和结果后续放在 `D:\PythonProject\mechanism`。

## 1. 研究主张和范围

首轮只判断是否存在可靠研究信号，不以寻找一个通用“偏见神经元”为目标。

研究问题：固定任务证据后，目标人物的社会属性和用户的无证据意见，对答案的影响是独立的，还是存在稳定交互？若有交互，能否定位于意见登记、证据读取或答案选择中的某个环节？

与最近文献的关系：

- [身份与意见的政治迎合研究](https://arxiv.org/abs/2608.29198)已经将身份和意见分开考察。本方案使用可核验任务真值、被判断对象的属性和正交证据条件，不能把一般的身份×意见设计当作新贡献。
- [迎合意见登记研究](https://arxiv.org/abs/2609.35822)已经区分意见处理和答案检索。本方案拟研究社会线索是否改变这条路径的作用，以及是否出现跨偏差交互。
- [双向偏见归因](https://arxiv.org/abs/2602.04398)已经做神经元去偏。新增价值应来自明确的机制假设与证伪，而不是再做一次 top-k 消融。

预设三个竞争解释：

| 假设 | 可观察预测 | 主要证伪方式 |
|---|---|---|
| H1 独立来源、末端叠加 | 社会线索和意见由不同上游组件处理；控制非线性后交互较弱 | 发现有选择性的上游路径干预能改变交互项 |
| H2 意见改变社会线索/证据的使用 | 意见条件改变特定检索路径对群体或证据 token 的依赖 | 路径替换无选择性效应，变化只来自通用读出破坏 |
| H3 通用答案选择造成表面共享 | 共同组件同样影响无社会属性的标签/答案选择任务 | 上游组件具有双重分离，且一般答案能力保持 |

这些只是建模假设；不将残差方向称作人类“信念”，也不由同一层的激活共变直接判断因果路径。

## 2. 成对、可核验的数据设计

从低知识要求的短文本问答开始，例如根据给定记录判断哪个人物完成某项任务。模板可参考 BBQ 的证据充分/不足设计，但新建明确的交叉条件；单纯身份事实读取另外作为能力对照。

固定人物的语义 ID 为甲、乙，答案为甲、乙、无法判断。显示为 A/B/C 时，另存标签到语义 ID 的映射。群体交换只改身份分配，任务证据仍绑定相同人物。

| 因素 | 条件 | 控制要求 |
|---|---|---|
| S：社会属性分配 | 两种交换分配 | 其余人物、事件、证据不变；初期只用一个属性维度 |
| U：用户意见 | 无意见 / 无证据地支持甲 / 无证据地支持乙 | 不能写成“我看过记录”等新增证据；语气和篇幅匹配 |
| E：证据 | 明确支持甲 / 明确支持乙 / 信息不足 | 前两者有独立可核验答案，后者正确答案为无法判断 |
| P：位置与标签 | 两种平衡排列 | 至少交换人物/答案的显示顺序；保留语义 ID |

先做 20 个根题检查任务可读性与模型格式遵循，再固定 60 个根题做第一批完整试验：`60 × 2 × 3 × 3 × 2 = 2160` 次评分/模型。这个数量是探索性预算，不能保证统计功效；后续按根题间方差与预期最小效应做样本量设计。

第一次先做一种语言；有可靠信号后再做人工审核的中英平行版本。为避免只在一个题材成立，根题涵盖至少三个短文本任务类型。根题的身份变体、翻译和所有模板改写必须处于同一数据分区。

建议试验切分：30 根题发现、10 根题调参、20 根题留出。因果主结论还需要新增独立根题和外部数据验证；不能把这个小留出集当最终论文规模。分区固定后，不根据留出效果换模板、换层或重新挑神经元。

数据字段至少记录：根题 ID、模板 ID、语言、S/U/E/P、完整输入、候选答案、语义 ID 映射、标准答案、群体交换关系、模型与 tokenizer revision、chat template、思考模式、dtype、解码配置。

## 3. 行为指标与交互指标

候选序列使用相同输出前缀计算条件 log 概率；多 token 候选对所有 token 求和，不能只取首 token。主实验优先轮换的单 token 标签，辅以语义候选和少量自由回答审计。完整序列评分对长度敏感，候选长度不匹配时增加标签/长度控制，不事后选择最有利的归一化方式。

对固定题目定义：

\[
D(s,u,e)=\log P(\text{甲}\mid x_{s,u,e})-\log P(\text{乙}\mid x_{s,u,e}).
\]

这里的概率指标签映射还原后的候选序列概率。用正负编码的两个社会分配和两个定向意见，定义固定证据条件下的交互：

\[
I(e)=\{D(+,+,e)-D(-,+,e)\}-\{D(+,-,e)-D(-,-,e)\}.
\]

这只是行为的差中之差，不是内部因果机制的证明。无意见条件另用于测量基线社会属性效应与意见增量。按根题聚合后报告平均值和配对 bootstrap 区间，同时报告任务/群体方向，避免正负偏差抵消。

并行指标：

1. 证据充分时的准确率，分别统计支持/反对刻板印象的条件。
2. 信息不足时选择“无法判断”的比例，以及在作出人物判断时的群体偏向。
3. 仅交换社会属性后的答案翻转率和候选分数变化。
4. 加入错误用户意见后的错误增量；正确意见是否仍可正常处理。
5. 输出格式失败、拒答、输出熵、非候选概率质量。
6. 身份事实抽取、同长度无社会属性文本问答与普通答案重排控制的表现。

`D` 不显示“无法判断”的概率，因此必须与上述概率/准确率一起报告。一个模型若把两个人物的概率都压到极低，不能仅凭人物 log 概率差宣布偏见变小。

全体样本是总体行为评估；另报告“无意见时可正确作答”子集以研究被意见诱导改错的机制。该子集应由独立基线运行预定义，不根据某个干预的救回效果筛选。

## 4. 从层到局部组件的定位

**阶段 A：表示基线。** 对身份、意见指向和证据指向分别训练每层线性探针；使用最后提示 token 和预定义语义位置。拆开这些标签可检查所谓“偏见方向”实际上是否只编码答案或身份。探针训练/评估严格按根题分开。

**阶段 B：粗粒度替换。** 在固定 S、E 时，用无意见条件的残差激活替换意见条件；再在固定 U、E 时比较社会属性交换。优先检查最后提示 token，随后检查意见、人物属性、证据对应位置。长度不同的输入按语义锚点对齐；跨语言不按原始 token 序号硬配。

**阶段 C：局部组件。** 根据发现集选择少量候选层，检查注意力头输出与 MLP 下投影前激活。筛选可用激活差或梯度归因，但最终效应需要精确前向替换确认。保留效应正负，不对差异取绝对值后统一清零。

**阶段 D：交互的因果验证。** 在完整 S×U×E 条件上使用同一个干预规则，重算 `I(e)`、基础社会属性效应和普通问答表现。不同条件不能各自挑选最有利的层和强度。路径级解释要求进一步证明上游来源经候选组件影响下游；只替换整块残差流不够。

**阶段 E：必要性、充分性与冗余。** 对候选组件做匹配均值/反事实替换、反向增加、联合干预和局部回填。必要性和充分性都只在所测输入、替换基线和候选集合下表述。联合效应非加性可能来自下游非线性，需与通用答案控制比较。

建议先在 50–100 个预定义成对样本上粗定位，再扩大验证；不在 2160 条输入上直接穷举全部神经元。所有选择来自发现/验证分区，留出分区只做冻结后确认。

## 5. 比较方法和 SAE 插入方式

基线分批加入，优先完成简单基线后再判断是否有必要扩展：

| 基线 | 用途 |
|---|---|
| 不干预；明确要求按证据回答的提示 | 确立原始能力与简单行为控制水平 |
| 每层均值差 CAA；方向投影 | 检查是否只需一个低维表示干预 |
| 同层随机方向/随机神经元 | 排除通用扰动或模型退化 |
| 真实 MLP 中间激活的带符号 top-k 干预 | 避免把弱神经元基线作为 SAE 优越性的依据 |
| SAE 单特征与特征集合 | 检查可解释单位是否有额外因果价值 |
| LEACE/SPLINCE | 路径选择性去偏分支的必要比较，适用条件与任务标签要明确 |

SAE 先确认与模型、层、hook 和归一化的一致性。本地 Qwen3-1.7B 不能仅因名称接近就默认兼容 Qwen3-1.7B-Base SAE。匹配未确认时，SAE 结果只能是迁移探索，不能与其他方法混作同条件主结果。

干预使用：

\[
h'=h+\operatorname{Dec}(z')-\operatorname{Dec}(z).
\]

单设 `h` 原样、只重构 `Dec(Enc(h))`、保留误差的特征编辑三种对照。单层 SAE 先检查重构误差、输出 KL 与任务保持率，必要时才探索更多层或本地训练。不能只用少量偏见测试句训练 SAE，再用同一批句子宣称发现一般性特征。

## 6. 资源与运行约束

建议从未量化 BF16、batch=1、256–512 token 开始；这是起始配置而非显存实测保证。层间缓存及时转 CPU，评分阶段不保留生成 KV cache；归因实验的梯度与缓存另行测峰值显存。

逐层加载 LLM/SAE 组件；SAE 训练采用离线激活缓存。第二模型用 MiniCPM5-2B 或 Qwen2.5-3B-Instruct 做独立发现和验证，不强行复用相同神经元编号。若第二模型基础能力不足，换低知识任务，不将随机作答误判为公平。

Qwen3 思考模式先固定关闭，用于简单评分实验；若后续研究思考过程，另建协议，记录提示格式与预算差异。实现前需按本地 tokenizer 的 chat template 核对具体开关支持，不能凭名称推断。

## 7. 决策门槛与可交付结果

第一轮以三道门推进：

1. **能力门。** 在无意见、证据明确条件下稳定高于机会水平，并具有足够题目可正确作答。可预设如 80% 准确率作为该简单任务的工程筛选线，但这不是文献给定的普遍标准；阈值需在看干预结果前固定。
2. **现象门。** 属性交换或意见条件在留出根题上有稳定效应，且不能由答案位置、词长或基础能力解释。如果交互项不稳定，就不启动“共享交互回路”的大规模分析。
3. **机制门。** 候选干预相较匹配随机对照，选择性改变目标效应；基本证据使用和任务能力保持，并在新模板与第二模型上验证适用范围。若只有普遍降置信度，则报告失败，不称为去偏机制。

每个阶段的交付物：冻结数据与分区、模型/配置记录、逐样本分数、配对效应与区间、组件筛选记录、干预强度曲线、能力保持结果。论文级证据还需要更大根题样本、外部数据、第二模型和与直接近邻方法的比较。

若方向一未通过现象门，可转向预先定义的问题：“哪些测量设置制造了表面上的跨偏差交互？”若经过严格控制仍没有内部共用路径，这也是对统一偏见方向假设的有限范围反证，不需要强行把负结果改写成正结果。
