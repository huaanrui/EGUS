# FBA/BBA 按类别参考轨道 v2（仅减少重复读出计算）

2026-10-13，主实验仍处于 KnowBias 定位阶段时制定，尚未运行新方法 dev/test。

主实验用统一跨维度集合评测全11类；本补充轨道保留公开 FBA/BBA 按维度定位的设置，在 Gender_identity、Nationality、Religion 上，分别使用已有对应维度的排名，独立在其 dev 题上选择 ratio / constant。主实验的方法与结果不改写。pre/post 都报告，不按测试挑版本。

每域同20个规范参数候选；dev 最大化准确率，使用同域 FairSteer 与原模型的消歧/偏见约束，以及该域干预作用于完整64道 MMLU dev 的能力约束。无可行候选则明确标记；测试前冻结所有12个域设置，测试题的类别只用于选择相应参数。这是带类别信息的参考基线，有额外路由信息，不能当作完全未知任务输入的部署策略。

共同三个类别共有192道 test 题（每类64），zero/few-shot 共384输出。原模型、FairSteer、证据门控在完全相同子集重新汇总；按类别内家族配对bootstrap，两个shot绑定。不得把这组成绩与全11类1408输出直接横比。

所有额外数据、提示、Qwen架构、生成位置、浮点与输入格式适配仍遵循主协议披露。只补充按域设置，不能称原模型/原提示/原题列表逐项复现。MMLU在每个域设置分别报告，不将它们平均冒充一个具有通用类别路由的系统。历史BBQ测试已被观察，为探索性比较。

v1 仅冻结了设计，尚未运行该轨道的拟合、选择或测试。v2 保留相同候选、顺序、标量读出形状、约束及数据；只计算当前类别真正用于评价的行，其他类别保留 baseline，从而避免每个域重复计算全 11 类。对实际参与评分的行与原函数做逐值核验，不改变选择规则。主实验 dev 的部分候选已可见，本修改不依赖其分数。

入口 scripts/run_bbq_readout_domains_v2.py；独立产物 domain_reference_v2/，源码/本说明/父计划哈希先锁定，参数在该轨道测试前锁定。v1 的冻结说明与源码保留。
