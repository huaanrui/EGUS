# FairSteer 作者协议迁移到 Qwen3-1.7B

作者公开代码：[LiYichen99/FairSteer](https://github.com/LiYichen99/FairSteer)，固定提交 `0545cdbaa71b3301030accf1b98130820e08026f`；论文：[ACL Findings 2025](https://aclanthology.org/2025.findings-acl.589/)。本轮是作者 BBQ 方法与预算的模型迁移，不是原论文各模型各基准的完整复现。

## 运行前固定设置

| 项目 | 本轮设置 |
|---|---|
| 模型 | 本地 Qwen3-1.7B，FP16，batch=1，SDPA |
| 提示 | 原始文本，无聊天模板，不生成思维链 |
| 方向样本 | 作者公开 BBQA.json 的全部 110 条：11 类各 10 条歧义题 |
| 方向构造 | 同题正确/刻板答案、zero/few-shot 各一对；答案 token 处逐层激活，float64 均值差，无长度归一化 |
| 检测器数据 | 全部 58,492 条 BBQ 的 zero/few-shot，加作者 MMLU 10,266 条 |
| 检测器标签 | 正确为 1；错误且选 target 为 0；其余 BBQ 错误剔除；作者 MMLU 全为 1 |
| 检测器划分 | 合并后 seed=42 打乱，随机行 4:1；无标准化、类别重加权 |
| 求解器 | 用户同意 sklearn LBFGS；L2、C=1、截距不惩罚、max_iter=10000、tol=1e-4 |
| 选层 | 11 类各 200 题，共 2200 题；全部 28 层、固定 α=1；最大整体准确率；平局选先出现的层 |
| 干预 | 同层检测为 0 时，仅最后 token 的 block 输出加原始方向 |
| 最终评价 | 全部 BBQ，原始选项顺序，zero/few-shot；整体/歧义/消歧准确率、作者有符号 BS(a)、BS(d)、分类别指标 |

检测器训练目标为 `sum(logistic_loss) + ||w||²/(2C)`。sklearn 与 cuML 目标相同，优化器、数值精度、停止准则仍不同，不能声称系数相同。收敛警告会使运行失败，避免静默接受未收敛模型；导出的系数需验证预测一致。

## 必须披露的差异

1. 作者没有公开 `generate_data/BBQ_test.json`，不能恢复原始 2200 题身份。论文明确的是每类 200 题、共 2200 题；本轮自行固定 seed=42、类别排序及无放回抽样算法，索引和哈希保存。论文没有提供这份选层集合的完整抽样程序，不能把这里的 seed=42 当作已确认的作者选层种子，也不冒充原始清单。
2. 原代码 cuML 在当前 Windows 环境不可用。2026-10-12 用户明确批准使用相同目标函数的 sklearn 求解器并披露差异；不再以 Docker 修复作为前置条件。
3. 模型替换为 Qwen3-1.7B；本地 Transformers 版本与作者时代不同。保存依赖版本、模型和源码哈希；实际使用 SDPA、仅计算最后位置 logits、不保留 KV cache，以降低无关内存开销。上述计算优化在 smoke 中检查捕获激活与不捕获时分数一致。
4. 没有进行原论文完整通用能力/其他偏见基准评价。因此 BBQ 消歧准确率不能替代完整通用能力评估。

原代码在全部评价 BBQ 上训练检测器，随机划分可能同时含同题 zero/few-shot。本轮为了协议对齐保留这个设置；结果只能解释为该作者协议下的表现，不能当作独立留出泛化证据。后续稳健性研究应另设独立家族测试。

## 本轮纠正的历史偏差

旧实验使用本地抽样 110 题，而非作者公开样本；预算远小于全量；使用 BF16 和多排列；选层与最终评价都使用 `(A)`。这轮分别对齐作者 `select_layer.py` 的 `(A)` 和 `evaluate.py` 的 `A.`。历史预测和已冻结计算代码保留，不用新设置覆盖旧结果。

保留作者 `hidden_states[1:]` 抽取：末层特征经过模型 final norm，而干预仍发生在原始 block 输出。smoke 测试明确确认这个末层不对称，避免暗中替作者修正实现。

## 验证与复跑

`tests/test_fairsteer_author.py` 从作者源码 AST 提取原始函数，逐字比较各阶段提示；随机全量预测对比作者 pandas 偏见统计。GPU smoke 检查关闭门控完全不变、强制干预改变 logits、移除 hook 恢复、隐藏状态位置及 FP16 有限性。

运行 `scripts/run_fairsteer_author.py all` 自动依次 smoke → directions → collect → fit → select → test → report。每 128 题保存；特征 memmap 约 14.6 GB。输出目录 `results/fairsteer_author_qwen3_v1`。源码/数据/配置冻结后不可修改再复用同一结果目录；报告渲染代码与计算代码分离。

正式评价使用收集阶段已有的基线预测，省去重复前向。最终干预预测逐题保存；选层完成即保存冻结计划，评价不能反向改选层或 α。
