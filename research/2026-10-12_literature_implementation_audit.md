**偏见干预预实验：论文方法与当前实现的对照审计**

调研日期：2026-10-12。审计对象：第一轮有效版本 v4、第二轮有效版本 `round2_20261012_v2`。本次阅读论文与作者代码、复算既有结果；没有运行新的模型实验，也没有更改已结束实验的算法、预测或结果文件。

**结论先行**

确实存在直接针对社会偏见、在小模型上得到明显干预效果的研究。前两轮结果不足以支持“表示方向、神经元、层和电路都无法干预偏见”。更准确的结论是：当前的数据对照、组件排序和干预算子组成的一组适配方法，在这份 Qwen3-1.7B 实验中没有得到可靠改善。

前两轮过早扩大了组合搜索，没有先建立忠于论文操作的有效参考基线。主要问题是**训练对照与目标不完全一致、不同方法共用的干预算子改变了原方法、用一种干预的定位结果限制其他方法的层搜索**。这些是已核实的方法差异；它们是否分别导致了多少性能损失，仍需要受控实验，不能把推断写成已证实的故障原因。

同时，论文中也有方法迁移失败、偏见方向反转，以及去偏伴随事实能力损失的结果。正确目标是先验证方法能产生预期的因果变化，再评价能否泛化并保留能力，而不是保证找到一个显著结果。

FairSteer 作者代码中的对比样本接入 `Answer: A/B/C`，采集最后的答案 token；方向是正确答案组均值减偏见答案组均值，代码没有归一化。推理时检测当前最后位置，触发后加向量。**拟合时的答案位置与推理时的待回答位置是两个状态，复现应明确记录。**论文的 110 条只对应方向估计；检测器的数据另有 58,492 条 BBQ 和 10,266 条 MMLU，按 4:1 划分。不能把它称为整个方法只使用 110 条监督数据，也不能认为其数据协议等价于我们的模板家族隔离。[论文 §4.2、附录](https://aclanthology.org/2025.findings-acl.589.pdf)，[作者向量代码](https://github.com/LiYichen99/FairSteer/blob/0545cdbaa71b3301030accf1b98130820e08026f/get_steering_vectors.py)，[作者输入构造](https://github.com/LiYichen99/FairSteer/blob/0545cdbaa71b3301030accf1b98130820e08026f/utils.py)。

CRISPR 的关键分数是 `B_i = A_i(y_wrong) − max(A_i(y_correct), 0)`，其中 `A_i(y)=h_i·∂P(y)/∂h_i`。它使用 token 最大值聚合、按错误混淆程度聚合样本，并平均多个同义指令；错误标签取最高概率的错误选项，不必然等于 BBQ 官方刻板选项。论文在 Flan-T5、T0 系列上做实验，不能把其效果直接当作 Qwen 的预期。它给我们的是更匹配任务的归因设计；移植到 decoder-only 和仅 MLP 子集时要标注为适配。[论文 §3、附录 A](https://arxiv.org/html/2311.09627)。

KnowBias 核心使用 45 个偏见知识问题。其作者代码在 Llama/Qwen 分支定位 `mlp.gate_proj` 输出，并在每次前向的最后位置对指定坐标乘以增强系数；**这与我们当前的 SiLU 门控乘积后、`down_proj` 前的激活不同**。直接搬用神经元编号而不对齐位置会改成另一种方法。代码中 `enhance()` 的 `mask_idx=-1`，`Patch.forward()` 执行乘法，已完成静态核查。该方法的额外知识问题属于额外监督，不能悄悄纳入“所有方法用同一份 BBQ fit”的公平比较。[论文](https://arxiv.org/html/2601.21864)，[定位代码](https://github.com/JP-25/KnowBias/blob/ccfd3daea0067707cbda6238839206c194794881/kn_code/knowledge_neurons.py)，[干预代码](https://github.com/JP-25/KnowBias/blob/ccfd3daea0067707cbda6238839206c194794881/kn_code/patch.py)。

安全任务的拒绝/服从切换和社会偏见任务的证据使用、人物绑定、刻板联想不是同一目标。前者的强效果支持其机制假设，不保证把相同名称的干预搬到 BBQ 仍有强效果。Safety-Neuron 本轮拿到了作者实现及论文页面，全文 PDF 获取受限，因此不声称完成了其所有正文/附录细节的核验。

SCAV 的自适应操作可以用线性分类器示意：`p(h)=sigmoid(wᵀh+b)`，单位方向 `v=w/||w||`；当概率超过目标 `p0` 时，沿 v 移动 `(logit(p0)−b−wᵀh)/||w||`。偏置、特征尺度变换和当前状态都参与距离计算。若应用到偏见，仍需用开发数据检查检测器是否识别正确概念，不能把安全论文的极端概率阈值直接视为最佳去偏强度。论文阈值与公开代码默认值还存在差异，应在复现配置中记录。[论文方法](https://arxiv.org/html/2404.12038)，[作者实现](https://github.com/SproutNan/AI-Safety_SCAV/blob/d28be837e6a7e1ba8f720f194f2b71f5424862e2/embedding-level/perturbation.py)。

1. **paired fit 对照没有直接构造“同题偏见回答→正确回答”。** 当前主要使用同一场景中身份与角色绑定变化的 native pairs，例如交换两个人物在上下文中的顺序，两个模糊题的正确答案仍都是 unknown。它可研究身份/顺序敏感性，但两端未必分别代表偏见和无偏。

   还有一个更具体的目标不一致：令 `m_a=logp(role0)−logp(role1)`。当 a 的刻板角色为 0、b 为 1 时，fit 用的 `bias(a)−bias(b)=m_a+m_b`；整状态 donor patch 的恢复目标却是 `m_b−m_a`。这两个量不同。用后一种整残差恢复给前一种方向选层，缺乏直接的目标一致性。[fit 构造](D:/PythonProject/mechanism/mechanism/round2.py:397)，[patch 计分](D:/PythonProject/mechanism/mechanism/round2.py:573)。

2. **当前“消融”把投影推到背景平均，不等于推到正确行为。** 当前方向操作为 `h′=h−αv[vᵀ(h−μ)]`；α=1 时 `vᵀh′=vᵀμ`。背景均值未必位于偏见分类器的无偏一侧。原始均值差的长度也在拟合时被丢弃，加法使用投影标准差作为单位，不能将我们的 α=1 与 FairSteer 的 α=1 比较。[干预算子](D:/PythonProject/mechanism/mechanism/round2.py:152)，[方向归一化](D:/PythonProject/mechanism/mechanism/round2.py:434)。

3. **先用不同任务选层，可能提前排除了有效位置。** 两个候选层来自身份-role 整残差 donor patch，另一个来自 block 更新量干预；随后方向、神经元和细粒度 token 变体主要围绕这三层展开。靠近最终读出的整状态替换直接替换了回答所用状态，恢复率高不足以说明该层有可泛化的偏见方向。应让各方法在自己的规范干预下选层，再比较预算。[搜索政策与实现](D:/PythonProject/mechanism/mechanism/round2.py:626)。

4. **神经元高相关、高归因和适合删除是三种性质。** 当前绝对激活差排序丢失了作用方向，可能把促进与抑制刻板回答的组件放在一起；单纯频率也可能选中重要但通用的组件。应对候选实际消融、增强、恢复，分别看有方向的目标变化和能力变化，而不是先删一个 top-k 集合就称为偏见电路。

5. **当前测试同时要求跨类别泛化。** 第二轮 test 是未参与 fit 的 Disability_status、Physical_appearance，不能和多数论文的同任务/同类别持出结果直接比。先在相同类别的新模板家族验证方法能工作，再把跨类别迁移作为独立问题。现有 test 已被查看；下一轮改方法后，它只能充当历史开发证据，确认性评价需要新封存的测试家族。

6. **有些问题已经排除，有些还未排除。** batch 内逐个 rotation 应用 Operator 的路径已核对；不是看到 `out[0]` 就能判定只干预了第一个 rotation。已有零强度、恢复、因果负对照通过。BF16 小 panel 存在少量 batch/精度预测差异，会影响小于 1pp 的变化，但不足以解释所有方法都没有大效果。当前证据主要指向实验构造与目标，未发现可据此宣称“一修就恢复论文效果”的单一实现 bug。[Runner](D:/PythonProject/mechanism/mechanism/model.py:67)，[既有完整结果](D:/PythonProject/mechanism/results/round2_20261012_v2/report.md)。

**论文的“改善”与我们采用的指标并不总是同一件事**

模糊 BBQ 题中，记 S=刻板人物回答率、C=反刻板人物回答率、U=unknown 正确率。在全部回答均归入三种合法选项时，官方有符号分数 `BS_amb=(1−U)·[2S/(S+C)−1]=S−C`。因此 S=C=0.3 时分数仍为零，却有 60% 的无依据人物回答。分数趋零既可能来自 S 下降，也可能来自 C 上升，不能单独证明更好地使用证据。

我们的 selection 基线宏平均 S=12.44%、C=11.55%，对应宏平均有符号差仅约 0.892pp；但测试类别的 S 更高。报告必须同时给出 S/C/U、明确题准确率和明确题 unknown 率，并区分宏/微平均。若有无效输出或采用自由生成，还须单列格式失败，以上简化不能无条件套用。[BBQ 分数定义在 FairSteer 附录 E.1](https://aclanthology.org/2025.findings-acl.589.pdf)。

BBA/FBA 提供了一个很有用的效用取舍实例：

|Llama-3.2-3B / BBQ|模糊题准确率|明确题准确率|相对基线|
|---|---:|---:|---|
|原模型|58.95%|84.61%|—|
|FBA|68.78%|81.59%|+9.83pp / −3.02pp|
|BBA|68.08%|79.95%|+9.13pp / −4.66pp|

这些作者报告的结果具有明显行为变化，但都超过我们设定的明确题最多下降 2pp 的容忍值。下一轮应先完整显示改善—能力损失曲线，再标注严格可接受区间，不能只列一个“通过/不通过”。这不改变前述事实：当前 20 个完整 selection 的无约束最好结果也仅为 0.31pp。[BBA 论文 Table 6](https://arxiv.org/html/2602.04398)。

**反例与负结果同样需要纳入判断**

- [GKnow，ACL 2026](https://arxiv.org/abs/2605.12299)：其电路与神经元分析发现事实性别信息与刻板性别关联纠缠；消融改善某些常用偏见指标时，可能同时削弱正确性别知识。它支持保留事实/能力控制，不支持“所有模型都无法去偏”的全称结论。
- [Fairness Pruning，2026-07 预印本](https://arxiv.org/html/2607.28319)：在人口属性最小对照上按差异激活选 GLU-MLP 神经元，得到双向变化和偏见反转；作者明确指出无符号排序混入作用相反的组件。其 Llama-3.2-1B 的八组实验中，模糊题 aggregate bias score 的总变动范围仅 0.80pp。大部分消融组合效果小并非只有我们的实验会出现，但这项工作也不能替我们证明当前实现正确。
- [INE](https://arxiv.org/html/2501.14457) 和 [GKnow](https://arxiv.org/abs/2605.12299) 共同提醒：需要区别“影响性别相关输出”与“只影响不当刻板判断”。只有干预效果，没有选择性，仍不足以完成机制解释。

**建议下一轮先完成的三个小实验**

顺序是本地现象确认 → 方法自身定位 → 小规模因果筛选 → token/组件消融 → 泛化。暂时不继续把 last-k 与所有方法展开成大网格。

|优先级|实验|保持论文要点|开发阶段首先回答的问题|
|---|---|---|---|
|1|FairSteer 风格同题双回答方向|记录答案位置；原始 DiM 长度；按每层实际效果选层；比较有/无检测门控|同题回答对照是否比身份-order 对照更能改变正确/错误回答 margin？是否只是 unknown 或答案字母方向？|
|2|CRISPR 任务归因 + INE 式因果筛选的适配基线|正确贡献保护项；有符号目标；候选实际干预重排；保留 token 节点信息|与激活差/RelP 相比，目标一致的候选是否更具选择性？消融与增强是否具有相反且可恢复的效应？|
|3|KnowBias 参考协议|单独声明知识问题监督；按作者 gate 输出与 last-token 增强定位|增强偏见识别能力是否比统一删除高相关神经元更有效？能否排除一般 Yes/No、规范措辞与拒绝效应？|

其中第 2 项是组合适配基线，不冒称某篇原论文的完整复现；第 3 项需要额外监督，单列参考轨道。BBA 的最终词表投影输入干预可加作低成本定位对照，但不能用其成功声称已经找到了中间 MLP 电路。

下一轮共同的数据与评估约定：

1. **两个轨道分开记录。** 论文参考轨道尽量保留原输入、数据来源和算子，用于检查本地行为是否可复现；公平比较轨道限定同一 BBQ fit 家族、标签信息、候选数量和开发预算。FairSteer 检测器缩小数据、KnowBias 从 fit 合成问题，均要明确命名为适配版本。
2. **将提取器和算子分开比较。** 先使用每种方法的规范算子确认其可用，再用同一算子比较不同提取器；另固定提取器比较加、减、零消融、均值替换、增强。这样能解释性能来自组件选择还是操作本身。
3. **按行为目标分别建对照。** 身份替换用于身份敏感性；同题错误/正确回答用于回答选择；有证据/无证据用于证据使用。不能用一个对照解释所有机制。模糊题可记录 `log P(S)−log P(U)` 与 `log P(S)−log P(C)`；明确题记录真实答案对其余选项的 margin，保留连续变化而不只看 argmax。
4. **选层先于 token 网格。** 每种方法先用规范 last-token 位置扫描自己的候选层；last token 必须区分 prompt 末尾、teacher-forced 答案末尾及生成阶段。选到有稳定信号的层后，再比较 last-k、身份词、问题末尾和 all-user-token；对当前一步输出没有因果路径的组合只作为负对照。
5. **保持可解释的共同控制。** 平衡 A/B/C 位置并使用全部六种排列做关键确认；同样大小的随机组件、相近扰动量的随机方向、标签打乱、相反方向、unknown 输出校准、事实性别/证据题都是必要参照。随机组件不应只有一个 seed。神经元与 residual 范数不能跨空间直接比较。
6. **严格接受与探索发现分开。** 报 S/C/U、连续 margin、明确题能力、弃答、一般任务保持和干预量；展示效用取舍，保留既有严格标准。按模板家族做置信区间，在 fresh holdout 上确认；不把探索中最大的一次变化当作已确认效果。
7. **先有因果证据再叫电路。** 需要必要性（删除）、充分性/保真度（保留并消融补集）以及恢复检验；若仅发现节点，结果名称保持“节点集合”。还应对照相同 token 预算和随机集合，避免把最后层强读出影响等同于完整机制。

本地现有 Qwen3-1.7B 可用于方法适配的开发检查；磁盘上的 Qwen2.5-3B-Instruct 可作为第二模型。两者不等于 KnowBias/BBA 的 Llama-3.2-3B 或 Qwen3-4B 原始骨干，因此不能把方法移植宣称为原配置复现，也不能预先承诺达到论文数值。当前没有必要先更换大显卡才能检查这些问题。

**创新判断也需要随这轮检索更新。** “增强识别偏见的神经元”已有 KnowBias；“事实性别和刻板性别的纠缠”已有 GKnow；“换一种 top-k 神经元删除”本身已很难成立为贡献。更有价值的候选问题是：在同一监督和干预算子预算下，不同提取器是否定位到相同的证据使用/回答选择过程，以及如何证明偏见改善没有退化成泛化弃答或损害事实性别能力。这是值得检验的研究问题，尚未因本次有限检索就被证明具有新颖性。
